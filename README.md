Sistema de Biblioteca

 Sistema simples de biblioteca desenvolvido para praticar Programação Orientada a Objetos (POO).

 O projeto permite gerenciar usuários, funcionários, livros, autores, exemplares, empréstimos e multas.

Funcionalidades

 - Cadastro de usuários
- Cadastro de funcionários
- Cadastro de livros e autores
- Controle de exemplares
- Empréstimo e devolução de livros
- Consulta de empréstimos
- Cálculo de dias de atraso
- Controle de multas

conceitos de POO

 O projeto utiliza conceitos como:

 - Herança
- Encapsulamento
- Classe abstrata
- Associação
- Composição
- Classes e objetos

 A classe `Pessoa` é abstrata e serve como base para `Usuario` e `Funcionario`.

 As demais classes representam os livros, autores, exemplares, empréstimos e multas do sistema.

 Objetivo

 O objetivo do projeto é aplicar os conceitos de POO em um sistema simples e próximo de uma situação real, seguindo a modelagem UML apresentada.
